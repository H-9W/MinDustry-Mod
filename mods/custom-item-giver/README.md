# 自定义面板（custom-item-giver）

> **版本**：v1.0 ｜ **适用游戏版本**：Mindustry 160+ ｜ **作者**：H

[**中文**](README.md) ｜ [English](README.en.md)

进游戏后屏幕上会多出一个「自定义面板」悬浮按钮，点击弹出面板，里面有**取物**和**加速**两个页签：
浏览/搜索任意物品并发放进你的核心仓库；给己方建筑与玩家单位按类别自定义加速。
纯客户端界面工具，不添加任何游戏内容，不会引起联机版本哈希冲突。

---

## 功能介绍

### 悬浮按钮（可拖动）
- 游戏进行中在屏幕角落显示「自定义面板」按钮（主菜单和结算画面自动隐藏）。
- **按住拖动**即可把按钮挪到屏幕任何位置，松手即存盘，下次启动还在原地。
- 轻点（位移不超过 10 像素）则是打开面板。

### 取物页
- 搜索或浏览**任意物品**（包含其它模组新增的物品），支持按显示名或内部名过滤，中文直接输（如「铜」）。
- 设定数量，或使用 `100 / 1k / 10k / 100k` 预设，也可以一键「每种都发」。
- 物品列表为单列卡片：图标、名称、**已有**数量（实时刷新）、`发放`、`+1`。

### 加速页（九类独立滑条，0 ~ 20 倍）
- 顶部是「开启加速」总开关，关掉后所有建筑与玩家单位立刻回到原版速度（不需要重启地图）。
- 九个类别各一根**独立滑条**（0 ~ 20 整数档位，0 或 1 = 原版速度）：

  `传送带 / 挖矿 / 制造 / 发电 / 炮塔 / 单位工厂 / 护盾 / 修复机 / 建造拆除`

- **推哪根哪一类变快**，其余类别保持原版速度。例如只推「挖矿」时，传送带和发电机一秒都不快。
- 注意：熔炉、化工厂、分离器归「制造」滑条，不归「挖矿」。
- 加速页整体可滚动，手机上也能用。
- 状态行实时显示「已开启 · 传送带×5、挖矿×2… · 我方 K 座建筑」，K 是当前真正吃到加速的我方建筑数量。

### 面板可拖动
- 按住面板**标题栏**就能把整个窗口挪走，关窗时位置一并记住，下次打开回到原位。

### 消除远程请求报错（Connection reset 弹窗）
- 游戏自己会发起两类远程请求（社区服务器列表 + 模组浏览器的远程模组列表），国内直连 GitHub 失败时会反复弹出「发生错误 (Connection reset)」。
- 本模组挡掉这两类原始请求，并改从 **ghproxy.net 镜像**拉取官方模组注册表填进模组浏览器，
  **远程模组列表照常可看**，弹窗不再出现。
- **开关**：不想走镜像（浏览器只显示本地已装模组），把 `scripts/main.js` 顶部的 `USE_MODLIST_MIRROR` 改成 `false` 后重新打包即可；挡弹窗的拦截逻辑不受此开关影响。

## 安装

### PC 端安装（zip）
1. 到本仓库 **Releases** 页面下载 `custom-item-giver-1.0.zip`。
2. **不要解压**，直接把 zip 文件复制到 `%APPDATA%\Mindustry\mods\` 目录
   （即 `C:\Users\<你的用户名>\AppData\Roaming\Mindustry\mods\`，若目录不存在则手动新建）。
3. 启动游戏，进入 **设置 → Mods（模组）**，找到「自定义面板」，把右边的开关打开。
4. 按提示**重启游戏**生效。

### 移动端安装（jar）
1. 到本仓库 **Releases** 页面下载 `custom-item-giver-1.0.jar`。
2. 用文件管理器把 jar 复制到手机内部存储的 `Mindustry/mods/` 目录：
   - 若该目录不存在，手动新建一个；
   - 部分设备的数据目录在 `Android/...` 下的 Mindustry 数据目录里，以你机器上已有的 Mindustry 文件夹位置为准。
3. 启动游戏，在 **设置 → Mods（模组）** 列表中找到「自定义面板」并启用，按提示重启游戏。

## 使用步骤

1. 进入任意地图（生存、沙盒、战役都可以）。
2. 点「自定义面板」按钮打开面板；按住按钮拖动可以把它挪到屏幕任何位置。
3. 面板顶部切换**取物** / **加速**两个页签；切页不会丢失你填过的数量、搜索词和每根滑条的档位。
4. 取物页：搜索或浏览物品 → 设定数量 → 点 `发放` 或 `+1`，数量会立刻体现在屏幕左上角的核心仓库计数里。
5. 加速页：勾选「开启加速」→ 把需要的类别滑条推到目标倍数。
6. 用完后点 × 关窗；面板和按钮的位置都会记住。

## 行为细节

- **物品去处**：优先放进本队**第一个核心**的仓库（就是左上角显示的那个总量）。
  直接写入、不受核心容量限制，属于工具型发放。
  没有核心时（裸图、编辑器测试图）改放进你当前操控单位的手持栏；手持栏一次只能装一种物品且有载货上限，超出部分游戏会丢弃。
- **仅单人/房主生效**：取物与加速只支持单人游戏（含自己当房主的听服地图）。
  多人客户端里点发放只会提示「物品由服务器管理」——客户端改本地数据会被服务器同步覆盖，这是设计如此，不是故障。
- **液体管道与载荷传送带不支持加速**：这两类是原版引擎本身不吃加速（`timeScale`），推了不会变快。
  这是原版限制，不是本模组漏做，加速页的说明文字里也写明了。
- **只影响我方**：敌方建筑的速度、敌人下一波的计时都保持原版。
- **不覆盖超频投影仪**：加速走引擎自己的 `applyBoost`（只往上取值），投影仪给得更高时以投影仪为准。
- **关掉自动恢复**：取消勾选或把滑条推回 0/1，建筑下一帧就衰减回原版速度，不会残留加速状态。
- **加速会一并提高燃料/电力消耗**：这是原版超频的同款代价（档位越高的钻头耗电越多），不是本模组额外加的惩罚。
- **建造拆除滑条**不作用于建筑，改的是玩家单位自己的建造/拆除速度；推回 0、关开关、换单位时都会还原。
- **位置保存**：按钮与窗口位置存在游戏的 `settings.bin` 里（键名 `cig-btn-x` / `cig-btn-y` / `cig-win-x` / `cig-win-y`）；
  想恢复默认，删掉这几个键即可。改分辨率/窗口拉伸后按钮若跑到屏幕外，会自动夹回可见区域。

## 故障排查

**装了但游戏里没有按钮？**
- 打开 **设置 → Mods**，确认「自定义面板」的开关是**开**的状态，然后按提示重启游戏。
  模组装进目录 ≠ 自动启用，必须手动打开开关。
- 确认游戏版本：本模组要求 **Mindustry 160 及以上**，旧版本无法加载。
- PC 端确认 zip 放的是 `%APPDATA%\Mindustry\mods\`，且**没有解压**（要整包放入）。

**模组列表里显示「该模组加载失败」/ 模组被自动禁用？**
- Mindustry 有脚本崩溃自动禁用机制：JS 一旦抛异常，游戏会自动关掉这个模组。
  恢复办法：设置 → Mods → 重新打开「自定义面板」的开关 → 重启游戏。

**还是弹「发生错误 (Connection reset)」？**
- 确认模组已启用（拦截逻辑由模组负责），启用后弹窗即消失。
- 模组浏览器列表为空不算故障：可能是镜像源暂时不可达，或你把 `USE_MODLIST_MIRROR` 设成了 `false`，
  两种情况都只影响远程列表显示，不影响取物与加速功能。

**点了发放按钮提示「物品由服务器管理」？**
- 你在多人游戏的客户端里。只有自己当房主或纯单人时才能发放与加速，详见「行为细节」。

**推了滑条没变化？**
- 检查「开启加速」总开关是否勾选；档位 0 和 1 都等于原版速度。
- 液体管道、载荷传送带本来就不支持加速（原版引擎限制）。
- 状态行里「我方 K 座建筑」为 0，说明这张图上没有对应类别的建筑。

## 模组文件说明

本目录下的每个文件是什么（玩家只需下载 Releases 安装包即可游玩，**不需要**改动以下任何文件）：

| 文件 | 是什么（中文说明） |
|---|---|
| `mod.hjson` | 模组的"身份证"：显示名、版本、作者等元数据，游戏靠它识别并加载模组（字段名必须为英文） |
| `scripts/main.js` | 模组的全部功能逻辑（JavaScript 源代码）；唯一可能需要手动改的是顶部 `USE_MODLIST_MIRROR` 开关 |
| `README.md` | 本手册（中文） |
| `README.en.md` | 本手册（英文版） |
